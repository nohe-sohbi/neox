# NEOX, a https://www.themoviedb.org metadata discovery app
User-agent: *
Allow: /

# /library and /search carry no public value, but they are deliberately NOT
# disallowed here: a disallowed URL is never crawled, so the noindex the app
# serves on those routes would never be read. Crawl allowed, indexing refused.

# /api is not disallowed either, for a different reason: the app is client
# rendered, so Googlebot fetches those endpoints while rendering the page.
# Blocking them here would leave it rendering an empty app. The API answers
# with `X-Robots-Tag: noindex` instead — fetchable, never indexed.
